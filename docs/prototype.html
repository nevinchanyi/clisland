Is it possible? Yes.

  • A macOS app can draw a borderless NSPanel over the menu bar, sized to the notch from NSScreen.safeAreaInsets and auxiliaryTopLeftArea. NotchNook and boring.notch do exactly this.
  • All three CLIs can run a shell command on lifecycle events, so they can tell the app what happened without any patching.
  • Context usage is readable: Claude Code passes it to the status line, Codex logs token counts to its session files, Gemini reports session stats.
  • Ship as a signed, notarized app via Homebrew cask, plus npx for the hook setup.

Notch states

  • Idle: slim black pill, one glyph per session, context ring for the busiest one.
  • Working: glyph pulses, a light sweep in the agent's color runs under the notch.
  • Done: notch drops open with a green ripple, project name, duration and the last reply line. Closes after 5s, leaves a green dot until you look.
  • Needs you: amber, stays open. Claude permissions can be approved right here.
  • Commands to run: when a reply asks you to run shell commands, each one gets its own Copy button, plus Copy all (one per line) and Copy as one line (joined with &&).
  • Hover: full list of sessions, click one to focus its terminal tab.

Copyable commands: how it works

  • The done event carries the final reply: Codex notify sends last-assistant-message, and Claude's Stop hook can read it from transcript_path.
  • The app pulls fenced bash / sh / zsh / console blocks, strips $ prompts and comments, joins \ line continuations, and keeps one command per row.
  • Copy uses NSPasteboard, so no extra permissions. An optional Paste into terminal button would need Accessibility access; keep it opt-in.
  • Commands stay attached to the session: the hover panel shows a 3 cmds chip until you dismiss them.

Install, for any developer

# app (signed + notarized)
brew install --cask clisland/tap/clisland

# wire hooks into installed CLIs, with backups
npx clisland setup
#  ✓ ~/.claude/settings.json   hooks + statusLine
#  ✓ ~/.codex/config.toml      notify
#  ✓ ~/.gemini/settings.json   hooks

npx clisland uninstall   # restores backups

What a hook entry looks like

// ~/.claude/settings.json (added by setup)
"hooks": {
  "Stop": [{ "hooks": [{ "type": "command",
    "command": "clisland emit --agent claude --event done" }] }],
  "Notification": [{ "hooks": [{ "type": "command",
    "command": "clisland emit --agent claude --event attention" }] }]
}

# ~/.codex/config.toml
notify = ["notch", "emit", "--agent", "codex"]

Before building: open-source prior art

Several free, MIT-licensed apps already do parts of this: Claude Island, CodeIsland, Coder Island (Claude + Codex), Claude Peek, Notchy, Open Island. Try two of them for a day, then decide whether to fork one or build fresh with multi-agent context tracking as the differentiator.
